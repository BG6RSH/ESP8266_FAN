# ESP8266 NodeMCU 风扇控制器接线方案

> 
> 主控：NodeMCU ESP-12E
> 输入：**TTP223 触摸传感器**（替代轻触按键）
> 输出：**双 MOS 管模块（N 沟道 MOS）** 驱动风扇 PWM 调速
> 代码引脚：
> 
> 
> - D7 (GPIO13) → MOS 管 PWM 调速
> - D5 (GPIO14) → 有源蜂鸣器
> - D1 (GPIO5) → TTP223 触摸输出

## 器件清单

1. NodeMCU ESP8266
2. TTP223 触摸模块
3. 双 N-MOS 管模块（常用 IRL540N，支持 PWM）
4. 有源 5V 蜂鸣器
5. 风扇（5V /12V），12V 风扇建议独立电源

## 接线总表

表格

| NodeMCU 丝印 | GPIO | 器件 | 接线说明 |
| --- | --- | --- | --- |
| D1 | GPIO5 | TTP223 OUT | TTP223 输出引脚；**TTP223 VCC=3.3V！不要接 5V，容易烧坏模块** |
| 3.3V | — | TTP223 VCC | 触摸模块供电 3.3V |
| GND | GND | TTP223 GND | 触摸模块地 |
| D5 | GPIO14 | 蜂鸣器 IN | 串 1kΩ 电阻接蜂鸣器信号脚；蜂鸣器 VCC=5V，GND=GND |
| D7 | GPIO13 | 双 MOS 模块 IN (PWM 输入) | MOS 模块 PWM 控制信号 |
| GND | GND | 双 MOS 模块 GND | **必须共地！非常重要** |
| MOS 模块 VIN | — | 风扇电源正极 | 5V 风扇：接 NodeMCU 5V；12V 风扇：外接 12V 电源正极 |
| MOS 模块 OUT | — | 风扇负极 | 风扇负极接 MOS 输出，风扇正极接 VIN |

> 
> 双 MOS 模块本质是两路独立 N 沟道 MOS，我们只用其中一路做风扇 PWM 调速，剩下一路闲置即可。
> ⚠️ MOS 管方案不需要三极管，驱动能力远强于 S8050，适合大电流风扇。

## TTP223 触摸模块重点说明

1. **供电必须 3.3V，严禁 5V 供电！** TTP223 很多版本 5V 供电会损坏，或者输出电平异常，导致 ESP8266 误触发。
2. TTP223 跳线：**保持锁存模式 OFF（点动模式）**，触摸一下 OUT 输出高，松开变回低，匹配现有按键代码逻辑。
   - B 板（带跳线）：跳线断开 = 点动模式（推荐）；短接 = 锁存模式（触摸一次保持高，再触摸才复位，不适合当前代码）
3. 代码中`KEY_PIN = D1(GPIO5)`，配置为`INPUT_PULLUP`

> 
> ⚠️ 这里有电平反转！原来代码是按键按下拉低；TTP223 触摸输出高电平。
> **需要修改 handleButtonPress 里电平判断逻辑！否则触摸不会生效**
   - TTP223 无触摸：OUT = 低；触摸：OUT = 高
